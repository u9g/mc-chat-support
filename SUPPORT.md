# MC Chat Support

For help with MC Chat, email [mc-chat@u9g.dev](mailto:mc-chat@u9g.dev).

Common questions:

- **Which servers work?** Minecraft Java Edition servers. Sign in with Microsoft for servers that verify accounts; servers that allow offline names accept the name you choose in Settings.
- **Why does the server see my IP?** MC Chat relays the connection through your phone on purpose, so the server treats you like a normal player.
- **Signing out.** Open Settings, pick the account, and remove it.
